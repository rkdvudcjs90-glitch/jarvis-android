기능 코드 기준: 3c52fcc045db1746d4d868759f6f3c229b7bdb4b.

## 목표
신고된 반복 안내/대화 불량을 올바른 앱 코드와 연결하고 다음 최소 수정 작업을 정한다.
현재 GitHub 0.5.3과 다른 작업 공간 0.4.8은 앱 식별자가 다르다. 임의로 하나를 다른 쪽에 덮어쓰지 않는다.

## 수행
1. AGENTS.md, CLAUDE.md, BASELINES.md와 현재 음성 서비스·API·정책 테스트·CI를 읽는다.
2. 호출→인사→듣기→요청→응답→대기/오류 복구를 코드 경로와 연결한다.
3. 인증/권한/한도/형식 오류, 무음, TTS 실패, 중복 시작/중단, 늦은 응답 처리의 빈틈을 확인한다.
4. 정적 의심과 실제 재현을 분리하고, 필요한 가장 작은 모의 검사나 재현 절차를 제안한다.
5. 현재 설치 앱을 여기서 확인할 수 없다면 필요한 식별 정보만 명시한다. 키·개인 음성·기기 일련번호는 요청하지 않는다.
6. docs/team/audits/TASK-001-claude.md에 근거 파일/라인, 우선순위, 최소 수정안, 검증 가능/불가 항목을 남긴다.

## 범위
- 이번 감사 작업은 docs/team/audits/의 보고서 작성과 관련 파일 읽기로 제한한다.
- 앱 기능·화면·CI·버전·서명·저장 데이터를 변경하지 않는다. 수정 작업은 감사 결과를 바탕으로 별도 항목으로 만든다.
